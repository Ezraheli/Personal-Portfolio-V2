## TIPS
- Recommended portrait image size: 600×800px or larger (3:4 ratio)
- Project thumbnails: 800×500px recommended (16:10 ratio)
- Gallery photos: any size — masonry layout handles it automatically
- Format: JPG for photos (smaller file size), PNG for logos/icons
- You can keep the old filenames — just update the src="" in index.html
