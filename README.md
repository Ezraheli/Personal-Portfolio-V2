Creative Portfolio – IT Student & Visual Artist

A modern, fully responsive personal portfolio website built with HTML5, CSS3, Bootstrap 5, and vanilla JavaScript. Features a Pinterest-style masonry gallery, dark/light mode toggle with #fcb100 brand color, animated project cards, show/hide projects, and a clean, engaging layout optimized for all devices (mobile, tablet, desktop). Perfect for showcasing creative work, IT projects, and photography.

🔧 Tech Stack: HTML5, CSS3, Bootstrap 5, JavaScript (ES6), Font Awesome / Bootstrap Icons

✨ Key Features:
- Dark / Light mode with persistent local storage
- Fully responsive (mobile-first design)
- Pinterest‑inspired masonry gallery with click-to-enlarge modal
- Project grid with hover overlay buttons & “Show More” toggle
- Smooth scrolling & interactive stats row
- Accessible, semantic HTML with focus on performance

📁 Assets: Includes placeholder folders for images, icons, and gallery photos.
📌 Created for Davao del Norte State College – IT student portfolio.
